# Misclassification Detection in E-commerce Catalogues

Find products listed in the wrong category in a large online clothing catalogue.

## Approach

- Text features with CountVectorizer, TF-IDF and Word2Vec
- Outlier detection with KMeans and DBSCAN
- Label checks using NLP and Random Forest
